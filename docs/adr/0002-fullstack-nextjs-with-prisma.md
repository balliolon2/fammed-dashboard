# 0002: Full-Stack Next.js with Prisma ORM

Rather than splitting the system into a decoupled frontend and a separate backend service (such as FastAPI or NestJS), we chose an all-in-one full-stack Next.js App Router architecture with Prisma ORM. This unifies type safety between clinical calculation engines and UI components, accelerates development of both client interactions and server persistence, and keeps operations manageable within a single codebase.
